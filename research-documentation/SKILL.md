# Technical Research

Prefer official documentation, release notes, source repositories, and reproducible examples. Check the version and date relevance. Cross-check important claims across trustworthy sources, link sources, and separate facts from inference. Do not copy secrets or private code into external services. Avoid inventing citations, flags, API methods, or compatibility guarantees. Summarize trade-offs and identify what remains uncertain.
