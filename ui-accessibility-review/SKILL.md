# UI & Accessibility Review

Inspect existing components and design tokens before editing. Check semantic HTML, keyboard navigation, focus visibility, accessible names, contrast, reduced-motion preferences, responsive layouts, form labels/errors, empty/loading/error states, and touch target usability. Reuse the existing design system and components. Avoid introducing arbitrary styles or dependencies. When possible run the project's accessibility checks and report limitations; don't claim full accessibility conformance based on a superficial review.
