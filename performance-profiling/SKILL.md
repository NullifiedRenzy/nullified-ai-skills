# Performance Profiling

Establish the user-visible symptom and measurable baseline first. Inspect likely bottlenecks and use available profilers, traces, query plans, or benchmark tools. Optimize the measured hotspot rather than guessing. Consider algorithmic complexity, network calls, caching, database queries, bundle size, and memory. Avoid premature complexity. Compare before/after results where possible and state the environment and limitations. Preserve correctness with tests.
