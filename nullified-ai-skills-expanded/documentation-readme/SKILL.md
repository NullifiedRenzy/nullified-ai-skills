# Documentation

Inspect implementation and existing docs before writing. Document prerequisites, supported versions, setup, configuration variable names (never secret values), common commands, API behaviour, troubleshooting, and limitations. Verify commands and paths against the repository. Keep docs concise, distinguish verified behaviour from assumptions, and update docs alongside relevant code changes. Do not invent features, badges, benchmarks, or compatibility claims.
