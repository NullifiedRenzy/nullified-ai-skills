# CI/CD & Releases

Inspect existing workflows and project scripts before adding pipeline steps. Keep CI deterministic, use least-privilege permissions, pin third-party actions where practical, and store credentials in the platform's secret store. Run lint, type checks, tests, and build steps appropriate to the project. Make release steps reversible where possible, document migrations and rollback plans, and ask before publishing releases, deploying to production, or changing repository permissions.
