# Discord.js Bot Development

Inspect the project's Discord.js and Node.js versions and current command/event architecture. Follow existing TypeScript and deployment patterns. Validate command options, check guild/member permissions server-side, handle interaction reply timing and errors, use rate limits responsibly, and log useful diagnostics without tokens or private message contents. Store bot tokens in environment variables or a secret manager; never commit them. Test permissions, missing configuration, API errors, and shutdown behaviour. Ask before granting broad Discord permissions or deploying changes.
