# Git & Pull Request Review

Inspect `git status` and the diff before making changes. Preserve uncommitted work. Review correctness, regressions, edge cases, test coverage, security, performance, compatibility, and clarity. Prioritize actionable findings and cite file/line references. Do not run destructive Git commands (reset, clean, force push, checkout over edits) without explicit approval. Suggest focused commits and clear messages; never commit secrets.
