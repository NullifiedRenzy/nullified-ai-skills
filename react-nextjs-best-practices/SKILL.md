# React & Next.js Best Practices

Inspect the repository and installed versions before choosing APIs. Follow the project's router (App Router or Pages Router) and conventions. Prefer server components where appropriate, keep client components focused, avoid unnecessary client-side JavaScript, handle loading/error/not-found states, use stable keys, and prevent avoidable re-renders. Optimize images and data fetching using supported framework features. Check accessibility, metadata, caching, and bundle impact. Avoid speculative rewrites; verify with the project's lint, type-check, tests, and build commands.
