# Accessibility Testing

Check semantic structure, heading order, labels, accessible names, keyboard operation, focus management, contrast, error messaging, responsive zoom, and reduced motion. Use automated tools where already available, then manually inspect keyboard flows because automation cannot prove accessibility. Avoid claiming WCAG conformance from a single automated scan. Report reproducible findings and prioritize barriers for users. Preserve existing UI conventions while recommending fixes.
